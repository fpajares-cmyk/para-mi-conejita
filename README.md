# Sorpresa para mi conejita 💛

Proyecto listo para subir a GitHub Pages.

## Archivos necesarios

Sube TODOS estos archivos a la raíz del repositorio:

- `index.html`
- `style.css`
- `script.js`
- `musica.mp3`
- `foto1.jpg`
- `foto2.jpg`
- `foto3.jpg`
- `foto4.jpg`

## Importante

La música debe llamarse exactamente:

`musica.mp3`

Las fotos deben llamarse exactamente:

`foto1.jpg`
`foto2.jpg`
`foto3.jpg`
`foto4.jpg`

Si quieres usar otros nombres, cámbialos también dentro de `script.js`.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos.
3. Entra a `Settings`.
4. Abre `Pages`.
5. En `Build and deployment`, selecciona `Deploy from a branch`.
6. Selecciona la rama `main` y la carpeta `/root`.
7. Guarda.
8. GitHub te dará el enlace público de tu página.

La reproducción de música empieza después de que la persona pulse el botón "Presióname", porque los navegadores normalmente bloquean el audio automático sin interacción.
